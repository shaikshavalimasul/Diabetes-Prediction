# Diadetes Prediction using Machine learning
## Project Overview
This project predicts whether a patient has diadetes or not
using machine learning classification algorithms.

## Dataset 
- Pima Indians Diabetes Dataset
- 768 patients records
- 8 features +1 target variable

## Lbraries Used
- Pandas
- Numpy
- Matplotlib
- Seaborn
- Scikit-Learn

## Models Used
- Logistic regression - 76.62%
- KNN - 77.92%
- Decision Tree - 68.83%

## Best Model
KNN with 77.92% accuracy

## Steps performed
- Data Cleaning
- Exploratory Data Analysis
- Feature Scaling
- Model Building
- Model Evaluation
